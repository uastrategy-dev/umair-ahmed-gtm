---
name: Portfolio redesign rules
description: Hard constraints for any visual work on the portfolio artifact
---

Any restyle of artifacts/portfolio must preserve ALL user-approved copy verbatim (headings, CTA labels like "Read case study", expandedTitle, mode badges). **Why:** an architect review failed a redesign for invented copy and a purple gradient stop. **How to apply:** diff copy strings against git history before finishing; check gradients for purple-ish hex values; avoid window.innerWidth in render (use CSS media queries).
